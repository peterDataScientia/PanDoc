# PanDoc application guide
This is maintained product knowledge, not evidence that a user has loaded or calculated anything.

PanDoc is a Streamlit workbench for molecular modelling and publication: complex selection, receptor and ligand preparation, AutoDock Vina docking, crystallographic redocking validation, result inspection and exports. Meeko prepares PDBQT inputs and reconstructs docked molecules. It does not run MD, experimental assays or interaction analysis. The assistant cannot execute calculations, change settings or search literature.

## Getting started and navigation
Use the Workflow sidebar: 1 · Load complex; 2 · Prepare structures; 3 · Validate docking; 4 · Run experiment; 5 · Explore results. The Assistant switch opens the chat alongside the workbench. Users can ask about PanDoc or science before loading anything. Only request missing data when necessary to answer an experiment-specific question. Never begin a general answer with a demand to load a structure.

## Load complex
Choose Upload file (PDB, CIF or MMCIF; 25 MB limit) or Search PDB. Search by Keywords, Protein name, PDB ID, UniProt accession or Ligand name / ID. Review entries and metadata with View structure details, then Load this structure. Downloads use mmCIF and record provenance. Select receptor components and Crystallographic reference ligand, choose one consistent alternate conformation (default or residue overrides), then Save component selection. The reference ligand must be removed from retained receptor components before redocking. Alternate conformations are alternative experimentally modelled positions, not additional atoms to keep simultaneously. After selection, choose 2 · Prepare structures in the sidebar.

## Preparation
Receptor tab: Structure checks automatically screen coordinates for duplicates, severe overlaps, possible missing heavy atoms, chain breaks and retained nonstandard components. These checks do not establish full chemical correctness. Rebuild missing heavy atoms with PDBFixer is optional; missing loops are not automatically built. Optional curated receptor PDB supports corrections made elsewhere. Meeko residue template assignments specify reviewed residue states, e.g. A:17=HID,A:32=ASH. Intended preparation pH (recorded context) records intent only: it does not automatically predict or assign protonation. Review receptor components and intended states, then Prepare receptor. Audit/check reports and preparation logs support troubleshooting. Failed residues are not silently deleted. An inferred-valence error may require reviewing geometry, alternate conformations, missing atoms and template compatibility; do not assert its cause without evidence.
Reference ligand tab: Find ligand chemistry from PDB obtains a candidate CCD identity/SMILES. Review and edit Reference ligand isomeric SMILES — editable. Compare experimental heavy atoms with expected chemistry and review stereochemistry/state, then Prepare reference ligand. Atom-count mismatch can mean incorrect identity, incomplete ligand, or wrong component selection; do not invent missing atoms. Original reference coordinates are preserved for redocking RMSD. Continue to Validate docking navigates after reference preparation.

## Docking box and calculations
Selecting a crystallographic ligand initially sets the box from its heavy-atom coordinate extrema. Each axis center=(min+max)/2; size=max-min+10 Å, adding 5 Å per side. This is the bounding-box midpoint, not the atom centroid. Users can edit Center X/Y/Z and Size X/Y/Z (Å), then Save docking box. The orange wireframe shows the box. Without a reference, the UI fallback is center [0,0,0], size [20,20,20]; these are placeholders and need a scientifically chosen site.
Search exhaustiveness defaults to 8; Maximum poses defaults to 9. Seeds default to 2026,2027,2028 for validation and 2026 for experiments. These are defaults, not evidence of the current saved protocol. Exhaustiveness controls search effort, not experimental affinity, and does not guarantee the global minimum. CPU use is capped at 2 in app settings.
Validate docking requires prepared receptor and crystallographic reference; Run redocking runs independent seeds. Run experiment supports preparing candidate ligands and Run docking. Record reviewed protonation, tautomers and stereochemistry. No automatic universal pH correction is performed. Jobs report progress and support Cancel job.

## Results and publication
Explore results selects a Calculation and Inspect pose; validation also provides Figure pose · sorted by RMSD. Display lowest-RMSD pose helps locate the best recovered pose. Rank means Vina's score rank within one search; lowest reference RMSD may not be rank 1. Vina score is in kcal/mol; lower scores are more favourable within its scoring function, not measured affinities. Crystallographic reference heavy-atom RMSD compares poses in the receptor coordinate frame with symmetry-aware matching and no ligand fitting. Vina's printed rmsd l.b./u.b. compare modes to its best mode, not to the crystal reference. The displayed pose-recovery threshold defaults to 2 Å but is adjustable. Report both top-ranked recovery and best-pose recovery across seeds; redocking success does not establish affinity prediction accuracy.
Publication figures show only crystallographic and redocked ligands, cyan/magenta by default, with a compact color legend. Both rotate together. PNG is 3996 × 2340 pixels at 600 DPI; PDF is 6.66 × 3.90 inches with a raster molecular panel. Source coordinates remain unchanged. Color/background/view are adjustable. Download results CSV, Download selected pose SDF and Download complete experiment export data, structures, settings and provenance.

## Answering from evidence
Explain procedures using exact controls above. Distinguish product defaults from supplied current settings. Explain general concepts without requiring an experiment. When asked to interpret a result or diagnose an error, use the supplied current snapshot, clearly note incomplete/partial data, and identify any specific missing information needed. Do not invent residue states, interactions, references or results. Draft methods only from supplied recorded facts, and identify missing details. Keep initial answers short and natural; expand on request.
